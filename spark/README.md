# Spark Project

## Introduction
This project is part of the Jarvis Data Engineering training program. The goal is to re-implement the London Gift Shop analytics workflow using Apache Spark so the solution can handle large-scale datasets in distributed environments. The project will be developed and tested in both Zeppelin on Hadoop and Databricks on Azure.

## Project Structure
- `notebook/`: contains Zeppelin and Databricks notebooks for PySpark analytics

## Status
This project is under development. Following GitFlow, final work will be merged after team code review.
